STEP 2 - Rebuild WaterSafety.zip
-----------------------------------------------------------------
This is the "Download All Resources" bundle on the homepage. It must be
rebuilt so teachers get the updated content.

Open PowerShell in that folder (Shift + right-click inside the folder in
File Explorer, then "Open PowerShell window here") and paste:

    Remove-Item WaterSafety.zip -Force -ErrorAction SilentlyContinue
    $files = Get-ChildItem -File | Where-Object {
      ($_.Extension -in '.html','.pdf','.pptx','.docx' -or
       $_.Name -in 'LICENSE','README.md','DATA_PROVENANCE.md') -and
      $_.Name -notlike 'google*' -and $_.Name -notlike 'yandex*'
    }
    Compress-Archive -Path $files.FullName -DestinationPath WaterSafety.zip
    "{0} files, {1:N1} MB" -f $files.Count, ((Get-Item WaterSafety.zip).Length/1MB)

It should report 96 files and about 17.8 MB. If it reports fewer than 96,
the copy in Step 1 was incomplete.

The google... and yandex... files are deliberately excluded - they are
search engine verification files and should not go to teachers.
