# swim-water-safety
Swim and water safety education resources for primary and secondary schools aligned with Australian and Victorian Curriculum 2.0

## Maintaining the data

Every published statistic, its source, and the exact files carrying it are mapped in [DATA_PROVENANCE.md](DATA_PROVENANCE.md), along with the annual update procedure and an audit script. Read that before refreshing figures.

### Data attribution — a condition, not a courtesy

Life Saving Victoria makes no intellectual property claim over this suite. Its requirement is that LSV data be attributed **inside the files that use it**. Every resource quoting drowning statistics carries the formal citation in its own footer, and this is reproduced in the PDF and PowerPoint versions so it travels with a downloaded file.

If you adapt these resources, retain those citations:
