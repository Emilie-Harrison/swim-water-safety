One further correction: a Year 9–10 extension task asked students to calculate how many Victorian lives "would be SAVED if Victoria's rate dropped to match the national average". Victoria's rate is *below* the national rate, so the task was logically incoherent. It now asks students to compute the expected deaths at the national rate, compare with the 52 actually recorded, and interpret the direction of the difference.

## 4. Annual update procedure

1. **Get the report.** lsv.com.au/what-we-do/research-advocacy
2. **Pull the headline numbers** from the Overview (p.6–7) and Fatal drowning (p.8) pages: total deaths, rate, ten-year average, variance, male/female split, location split, non-fatal total.
3. **Recalculate the derived figures.** These are not in the report — they are computed in the teaching content:
   - Rate working: `deaths ÷ 69` (Victoria ≈ 6.9M, i.e. 69 units of 100,000)
   - Male percentage: `males ÷ total × 100`
   - 15–24 share expressed as "about 1 in N"
4. **Update in this order:** HTML → regenerate PDFs → update PPTX → re-export deck PDFs → rebuild `WaterSafety.zip`.
5. **Update the citation** in the footer block of every page (search `Data sources cited in this resource`) and on the licence slide of both decks.
6. **Update the What's New card** on `index.html` and the footer date on `water_safety_resource_directory.html`.
7. **Re-run the audit** (section 5).

### Where the arithmetic lives

Changing the headline total breaks worked examples, quiz answer keys and multiple-choice distractors. These files contain **calculations**, not just quoted figures — check each one by hand:

- `advanced_water_safety_year910_quiz_bank.html` — rate calculation Q, answer key, A-standard sample answer
- `water_safety_interactive_quiz.html` — JavaScript question array, options and feedback strings

## 5. Audit script

Run from the repo root after any data update. Returns 0 on every line when clean.

```python
import glob, re, subprocess
html = [f for f in glob.glob('*.html') if not f.startswith(('google','yandex'))]
OLD = r'54 fatal|54 drowning|0\.78 per|46 of 54|highest in over a decade'   # update each year
checks = {
  'stale figures': OLD,
  'false unpatrolled claim': r'[Aa]ll \d+ (?:Victorian )?(?:drowning )?deaths.{0,95}unpatrolled',
  'dead LSV url': r'research/victorian-drowning-reports|toolkit/[a-z_]+\.php',
  'wrong parks domain': r'www\.park\.vic\.gov\.au',
}
for label, pat in checks.items():
    print(label, sum(1 for f in html if re.search(pat, open(f, encoding='utf-8').read())))

# citations and licence present in every page
for tag in ['Data sources cited', '"license"']:
    print(tag, sum(1 for f in html if tag in open(f, encoding='utf-8').read()), '/', len(html))

# PDFs carry the new year, the licence and the citation
def txt(f): return subprocess.run(['pdftotext', f, '-'], capture_output=True, text=True).stdout
pdfs = glob.glob('*.pdf')
print('PDFs stale:', sum(1 for f in pdfs if re.search(OLD, txt(f))))
print('PDFs missing licence:', sum(1 for f in pdfs if 'CC BY 4.0' not in txt(f)))
print('PDFs missing citation:', sum(1 for f in pdfs if 'Victorian Drowning Report' not in txt(f)))
```

## 6. Two claims to keep out

Both were corrected in September 2026. If either reappears, it is wrong.

**"Highest in over a decade."** Applied to the 2023–24 total of 54. Victoria recorded 64 in 2020–21 and 59 in 2022–23. Use variance against the ten-year average instead — it is accurate and does not go stale in the same way.

**"All deaths occurred at unpatrolled locations."** Used across the suite as the argument for swimming between the flags. It does not hold: in 2024–25, 25% of deaths were in home environments — pools, bathtubs, dams — which no patrol reaches. The defensible version is that Victoria recorded zero public-pool drowning deaths, the first time since 2019–20.
